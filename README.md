## 👋 Tentang saya

Saya membangun aplikasi web end-to-end — dari ide, antarmuka, sampai deploy — dan proyek Web3 di BNB Smart Chain.
Kebanyakan dibangun bersama AI agent sebagai partner coding: saya yang pegang arah dan keputusan, agent yang bantu eksekusi.

- 🔭 Sedang membangun: **PawCats** (koleksi NFT BSC) & **VinkyWeb** (jasa pembuatan website)
- 🌱 Fokus belajar: smart contract, otomasi, dan sistem AI agent
- 🎯 Prinsip: proyek kecil yang **selesai dan bisa dipakai**, bukan sekadar demo

## 🚀 Proyek unggulan

- **PawCats** — Koleksi NFT di BSC (Fase 1 sold out, Fase 2 live) + token PAW dan marketplace sendiri. Kontrak terverifikasi Sourcify: [pawcats-contracts](https://github.com/alvinebintang24/pawcats-contracts)
- **Hash Nonce** — NFT puzzle ERC-721 dengan mining proof-of-work (keccak256) dan pasar internal.
- **VinkyWeb** — Brand jasa freelance: pembuatan website + desain banner & konten sosial media.
- **NgejedogBetta** — Website penjualan ikan cupang: katalog, filter, keranjang, dan checkout lewat WhatsApp.
- **Kliper** — Pipeline konten YouTube Shorts: render vertikal 720×1280 otomatis (Python + ffmpeg), dengan Kaggle Notebooks (GPU T4 gratis) sebagai mesin render tambahan.
- **Musehood** — Aplikasi grup chat multi-AI fullstack: 7 kursi AI + kursi admin, gateway OpenAI-compatible, pipeline tugas berurutan, dan UI ala WhatsApp.
